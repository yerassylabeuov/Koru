# Koru
The code PROTOTYPE for "Koru," AI-glasses for the visually impaired. The principle of the detection of a distance to obstacles is stereovision (using pictures from different perspectives to calculate distance). Team of Koru: Artur Shtro, Yerassyl Abeuov, Batyrkhan Mukhtarkhan, Dias Amanzhol, Kulkenova Maryam, Timofey Schannikov. 

In order to run the code, run this:
pip install numpy opencv-python tensorflow

python koru_prototype.py demo
